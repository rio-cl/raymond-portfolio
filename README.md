## Running the Project Locally

### Requirements

Node.js and npm must be installed.

### Installation

Clone the portfolio repository and navigate into its directory.

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Open the local address displayed in the terminal.

### Production Build

```bash
npm run build
```

The compiled website will be generated in the `dist` directory.

## Deployment

The portfolio is intended to be deployed using Vercel.
